- Câu chuyện cross-sell: mua GPU gợi ý PSU, mua laptop gợi ý chuột và túi
- Bốn persona để sinh dữ liệu có logic, và nguyên tắc nói thật về dữ liệu giả lập

- Ghi ADR cho mỗi quyết định
- Tách handler → service → repository; tránh microservices cho có

## Bốn chỗ đã sửa

### 1. Personalize có thể không mở được trên tài khoản Free plan

> Cập nhật 01/10/2026: mentor khuyên không dùng Personalize; nhóm tự xây mô hình gợi ý trên Lambda + DynamoDB ([ADR-0016](adr/0016-tu-xay-mo-hinh-goi-y.md)).

- **Kế hoạch cũ:** dùng Personalize trên tài khoản của nhóm; rủi ro chỉ là thời gian train.
- **Thực tế:** Free plan chỉ có ưu đãi Always Free, không có bản dùng thử ngắn hạn, nên 2 tháng dùng thử của Personalize không áp dụng. Tài liệu AWS về luồng đăng ký mới xếp Personalize vào nhóm chỉ dành cho Paid plan.
- **Sửa:** kiểm tra trên console (Create dataset group). Nếu bị chặn, hỏi mentor có được nâng một tài khoản lên Paid plan không. Làm gợi ý baseline trước; Personalize cắm vào sau.

### 2. Campaign tính tiền cả ngày lẫn đêm

- **Kế hoạch cũ:** ADR-002 cho rằng Personalize "không phát sinh chi phí như lo ngại ban đầu".
- **Thực tế:** campaign real-time bị tính tối thiểu 1 request mỗi giây dù không ai gọi. Recipe cũ khoảng $0,20/giờ (~$146/tháng); recipe v2 khoảng $0,54/giờ (~$394/tháng).
- **Sửa:** dùng batch inference làm mặc định, ghi kết quả vào bảng DynamoDB, web chỉ đọc bảng đó. Campaign chỉ bật 1–2 giờ khi demo, có Lambda hẹn giờ tự xoá campaign sống quá 3 giờ. Đây cũng là luận điểm business: shop nhỏ làm mới gợi ý mỗi đêm là đủ, chi phí gần 0.

### 3. Load test 10.000 người và bản EC2 đầy đủ

- **Kế hoạch cũ:** load test 100 → 1.000 → 10.000 người; bản EC2 chạy cả luồng xem và đặt hàng.
- **Thực tế:** AWS hạ hạn mức Lambda chạy đồng thời của tài khoản mới; ở 10.000 người thứ đo được chủ yếu là lỗi throttle. Xây shop hai lần quá sức 3 người trong 8 tuần.
- **Sửa:** xem Service Quotas → AWS Lambda → Concurrent executions; chạy k6 ở 50, 200 và 1.000 người ảo vào thẳng API Gateway. Bản EC2 chỉ cần `GET /products` và `POST /orders` bằng Express + MySQL chạy Docker Compose, chỉ bật lúc test.

### 4. So AI với baseline đang tự chứng minh điều nhóm cài vào

- **Thực tế:** dữ liệu giả lập đã cài sẵn quy luật (70% theo persona, 40% đơn GPU có kèm PSU); Personalize tìm lại được là chuyện đương nhiên.
- **Sửa:** chia train/test theo thời gian; dùng recipe `aws-popularity-count` làm baseline để cùng bộ chỉ số; ghi rõ đây là kiểm chứng pipeline. Dư thời gian thì chạy thêm trên bộ dữ liệu thật công khai như Amazon Reviews 2023 (mảng Electronics).

**Nếu mentor không duyệt Paid plan:** Nhân viết luật mua kèm bằng Python (support, confidence, lift), chạy mỗi đêm, ghi vào cùng bảng DynamoDB. Web và kiến trúc không phải sửa gì.

## Kiến trúc: những chỗ đã đổi

| Thành phần | Kế hoạch cũ | Đổi thành | Vì sao |
|---|---|---|---|
| Frontend | Next.js trên S3 | React + Vite, hoặc Next.js static export | S3 chỉ phục vụ file tĩnh |
| Cửa vào | CloudFront → S3; API Gateway riêng | Một CloudFront: `/` → S3 (OAC), `/api/*` → API Gateway | Một WAF bảo vệ cả hai; cùng tên miền nên không có CORS; gói CloudFront Free có WAF 5 rule |
| API | API Gateway + Cognito authorizer | HTTP API + JWT authorizer của Cognito | Rẻ hơn REST API ~3,5 lần; có throttle theo route |
| Gợi ý | Lambda gọi campaign real-time | Bảng `recs` do job batch ghi; API chỉ đọc bảng | Không phí tối thiểu; so AI với baseline chỉ là đổi nguồn |
| Sự kiện | Lambda ghi event vào S3 | Event vào DynamoDB; `PURCHASE` chỉ do service đơn hàng tạo | Người dùng không giả được sự kiện "đã mua" |
| Mạng | Chưa nhắc | Lambda không đặt trong VPC | Không cần NAT gateway (~$1–1,5/ngày) |
| Bí mật | Secrets Manager | Parameter Store (SecureString) + 1 KMS key | Không có bí mật cần xoay vòng |
| CI/CD | CodePipeline | GitHub Actions + OIDC | Không có access key nào tồn tại |
| Phát hiện tấn công | GuardDuty | CloudTrail + CloudWatch alarm + log WAF | Free plan không có trial GuardDuty |

## Docker dùng ở đâu

| Việc | Docker làm gì | Ai |
|---|---|---|
| Dev trên máy | `docker compose` chạy DynamoDB Local | Hoàng, An |
| Test integration | Testcontainers tự bật DynamoDB Local cho mỗi bộ test | Cả nhóm |
| Đóng gói Lambda | CDK cần Docker để đóng gói Lambda Python | Cả nhóm |
| Bản đối chứng | Express + MySQL bằng Docker Compose trên EC2 | An |
| Tuỳ chọn | Lambda dạng container image trên ECR nếu job Python cần thư viện nặng | Nhân |

Không chạy API chính trên ECS Fargate: phải thêm Load Balancer (~$16–18/tháng) trong khi Lambda gần như $0 ở quy mô này.
