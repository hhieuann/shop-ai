## 3. 16/10: người dùng E2E cho staging (An)

Cùng cách đã làm ở dev (#83). An tự chạy lệnh và tự gõ mật khẩu.

```bash
aws cloudformation describe-stacks --stack-name shop-stg-api --query "Stacks[0].Outputs" --output table
```

Lấy `UserPoolId` và `UserPoolE2eClientId` từ bảng kết quả, rồi tạo user:

```bash
aws cognito-idp admin-create-user --user-pool-id <UserPoolId> --username e2e-user@example.com --message-action SUPPRESS
```

```bash
aws cognito-idp admin-set-user-password --user-pool-id <UserPoolId> --username e2e-user@example.com --password '<mật khẩu mạnh>' --permanent
```

- [ ] Environment `staging` trên GitHub: biến `E2E_USERNAME`, `E2E_COGNITO_CLIENT_ID`; secret `E2E_PASSWORD`
- [ ] Chạy lại workflow staging (Re-run) nếu đã có collection E2E của Hoàng, xem bước E2E xanh
