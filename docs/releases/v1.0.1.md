Hết giới hạn "đổi người đăng nhập ở tab khác" (#508, sửa ở #515) và "xác thực hai lớp chưa có trên web" (#183, có ở #502). Còn lại:

- **Gọi thẳng API Gateway bỏ qua WAF** (C1): vẫn chấp nhận; còn throttle stage và JWT cho mọi route ghi.

- **Mất thiết bị tạo mã:** khách liên hệ shop, admin xác minh rồi tắt hộ (account.md BR-10, threat model L12); chưa có mã dự phòng.
- **Sản phẩm chưa có ảnh** (#530).
