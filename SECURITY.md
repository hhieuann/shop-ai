# Chính sách bảo mật

## Phiên bản được hỗ trợ

Chỉ bản mới nhất trên nhánh `main`, là bản đang chạy ở môi trường demo.

## Báo lỗ hổng

Không mở issue công khai. Dùng **Security → Report a vulnerability** của repo này (GitHub private vulnerability reporting).

Gửi kèm:

- Mô tả lỗ hổng và mức ảnh hưởng
- Các bước tái hiện, request mẫu nếu có
- Phiên bản hoặc commit bị ảnh hưởng

Nhóm phản hồi trong 72 giờ. Đây là dự án học tập của sinh viên, thời gian sửa tuỳ mức độ nghiêm trọng.

## Phạm vi

- Code trong repo này
- Web và API demo do nhóm triển khai

Không được: tấn công từ chối dịch vụ, spam, dò tìm thông tin cá nhân, tấn công tài khoản AWS hay hạ tầng của bên thứ ba. Môi trường demo chỉ chứa dữ liệu giả lập.

## English

Please report vulnerabilities privately via **Security → Report a vulnerability**. Do not open public issues. We aim to respond within 72 hours. Denial-of-service testing and attacks against third-party infrastructure are out of scope.
